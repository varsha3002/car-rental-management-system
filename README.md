# Car Rental Management System

A full-stack web application that allows users to explore available cars, make rental bookings, and manage their reservations.

## Technologies Used

- **Frontend:** React.js, Vite, CSS
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **API:** REST API
- **Tools:** VS Code, MySQL Workbench, Git, GitHub

## Features

- Customer registration and login
- Browse available cars
- Filter cars by seating capacity, mileage, and budget
- Select rental and return dates
- Calculate estimated rental costs
- Create and manage rental bookings
- Admin dashboard for managing cars, customers, and bookings
- Demo payment workflow

## Project Structure

- `car-rental/` — Spring Boot backend
- `frontend/` — React frontend

## How to Run

### Backend

1. Configure your MySQL database.
2. Set your database credentials using environment variables.
3. Run the Spring Boot application.

### Frontend

1. Open a terminal in the `frontend` folder.
2. Install dependencies:

   `pnpm install`

3. Start the development server:

   `pnpm run dev`

## Note

The payment workflow is a simulation and does not process real payments.
